# TraktGram

Your Trakt.tv library, inside Telegram.

TraktGram is a Telegram client for [Trakt.tv](https://trakt.tv), bringing your watch history, watchlist, recommendations, ratings, and show progress directly into Telegram.

[@TraktGram_bot](https://t.me/TraktGram_bot)

## Features

- 🔐 Trakt OAuth login
- 🔄 Switch between Trakt accounts
- 🔥 Trending movies and shows
- 📋 Watchlist and watch history
- 🎯 Recommendations
- 🎬 Movie and show details
- 👥 Cast, posters, ratings, and personal status
- ✅ Mark movies and episodes as watched
- 📅 Custom watch dates
- ⭐ 5-star ratings with half-star support
- 📺 Season and episode progress
- ▶️ Next-episode tracking
- 👀 Trakt check-ins
- 🔎 Inline search from any Telegram chat
- 📱 Telegram Mini App with profile and watch activity

## Commands

/start · /login · /me · /stats · /trending · /history · /random · /help · /ping · /cancel

Or search inline:

@TraktGram_bot <title>

## Stack

TypeScript · Grammy · Cloudflare Workers · Cloudflare KV · Trakt API
